Sobre o Projeto

Conheça um pouco mais sobre o sistema de ouvidoria FalaAí.

O que é o FalaAí?

O FalaAí é um sistema de ouvidoria desenvolvido com Flask que permite o envio de sugestões, elogios e reclamações de forma simples, rápida e totalmente anônima.

Objetivo

Oferecer um canal seguro para que alunos, colaboradores ou clientes possam registrar manifestações e contribuir para a melhoria contínua de escolas, empresas e instituições.

Funcionalidades

Cadastro de manifestações
Visualização das mensagens
Edição de manifestações
Exclusão de manifestações
Pesquisa por palavras-chave
Armazenamento em arquivo JSON

Tecnologias Utilizadas

Python
Flask
Bootstrap
HTML5
CSS3
JSON

Desenvolvido para demonstrar a utilização do Flask, Bootstrap e JSON na construção de um sistema simples de ouvidoria.
