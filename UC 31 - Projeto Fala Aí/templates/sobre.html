FalaAí

Sistema de Ouvidoria para Sugestões, Reclamações e Elogios Anônimos.

Sobre o Projeto

O FalaAí é um sistema web desenvolvido utilizando Python, Flask, HTML, CSS, Bootstrap e JSON.

Seu objetivo é oferecer um canal simples, seguro e totalmente anônimo para que usuários possam registrar sugestões, reclamações ou elogios.

Objetivo

Melhorar a comunicação entre instituições e seus usuários, permitindo que qualquer pessoa participe de forma anônima e contribua para a melhoria contínua da organização.

Principais Recursos

Manifestações

Cadastro de sugestões, elogios e reclamações.

Pesquisa

Busca rápida por título, descrição ou categoria.

Administração

Edição e gerenciamento das manifestações.

Exclusão

Remoção de registros desnecessários.

Anonimato

Nenhum dado pessoal é solicitado aos usuários.

Responsivo

Compatível com computadores, tablets e celulares.

Tecnologias Utilizadas

Python
Flask
Bootstrap
HTML5
CSS3
JSON
Desenvolvido para a UC31

Projeto acadêmico criado para demonstrar a utilização do Flask, Bootstrap, HTML, CSS e JSON na construção de uma aplicação web moderna, responsiva e acessível.
